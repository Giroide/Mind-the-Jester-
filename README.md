# Mind the Jester!

A short, basic browser game built with Vite, JavaScript, HTML, and CSS where you collect and bank points to complete quests.

## Tech Stack
- Vite
- Vanilla JavaScript
- HTML5 & CSS3

## Run Locally

1. Clone the repository:
   ```bash
   git clone [https://github.com/Giroide/Mind-the-Jester-.git](https://github.com/Giroide/Mind-the-Jester-.git)

2. Install dependencies
    ```bash
   npm install

3. Start the development server
   ```bash
   npm run dev
